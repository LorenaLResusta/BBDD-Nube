# UD01 · Triar l'emmagatzematge

Abans de crear un sol recurs cal decidir **on va cada dada**: no és el mateix una foto que es descarrega un milió de vegades, el disc d'una base de dades o una carpeta que compartixen deu servidors. En esta unitat aprens a traduir les necessitats de l'empresa a un tipus d'emmagatzematge, una regió i una classe, i a calcular quant costarà.
